# 模板库（templates/）

模板 = 创作约束 + 默认图表策略，**不包含任何数字**。
同一数据换模板，所有数字、单位、口径保持一致（阶段验收标准之一）。

| 模板 | 目录 | 适用叙事 |
|---|---|---|
| 趋势 | `trend/` | 指标随时间的变化、拐点解读 |
| 对比 | `comparison/`（规划中） | 类别/方案横向比较 |
| 记分卡 | `scorecard/`（规划中） | 多指标经营复盘 |
| 解释 | `explainer/`（规划中） | 概念/机制拆解 |

新增模板：复制 `trend/template.yaml`，修改 `brief` 与 `defaults`，
在 `README.md` 登记。模板文件自身遵循 MIT；模板引用的外部素材须在
`THIRD_PARTY.md` 登记许可。

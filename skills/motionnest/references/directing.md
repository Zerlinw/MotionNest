# 导演与节奏（references/directing.md）

## 镜头时长与认知负荷

| 信息密度 | 建议时长 | 说明 |
|---|---|---|
| 片名/结论卡 | 2.0–2.5s | 一句话结论，不堆数字 |
| 单图表 + 一个数字 | 3–5s | 一镜一个断言 |
| 对比/结构图 | 4–6s | 需要读数时间 |
| 转场 | 0.5–1.0s | 不抢内容 |

总时长默认 30s（对外）或 20s（社交）；超过 60s 必须拆分主题。

## 节奏单（rhythm sheet）

分镜的每个镜头在生成前必须落成节奏单：`shot_id / start_ms / duration_ms / scene_type / assertion`。
节奏单未写完不许进入动画生成——这是"先规划后渲染"的硬顺序。

## 先攻最难镜头

质量风险最高的镜头（最复杂的图表、最关键的数字）优先生成并审，
不要按时间顺序平均用力。

## 运动语言白名单

动画原语仅允许：`fade / slide-up / slide-down / scale / draw / count-up`。
一镜至多一个 enter 原语；禁止无信息量的装饰运动。

# 图表表达规则（references/chart-rules.md）

## 图元选择

| 数据问题 | 推荐图型 | 禁忌 |
|---|---|---|
| 跨类别比大小 | bar | 用折线表达类别比较 |
| 随时间变化 | line / area | 用饼图表达时序 |
| 构成占比 | donut（≤5 项） | 超过 5 项仍用饼图 |
| 两变量关系 | scatter | 用气泡图堆无关维度 |

## 数值呈现

1. 数值必须带单位（单位来自数据字典，缺失时数据门禁告警）；
2. 百分比必须可回到分子/分母（口径写在 `metric_definitions`）；
3. 同比/环比必须标注基期；
4. 一屏至多一个主结论数字；其余为支撑。

## 可读性门禁（视觉门自动检查）

- 同屏文字 ≤ 40 字符；
- 图层 ID 全局唯一（定点改稿的锚点）；
- 图表图层必须声明 `chart_type` 与 `series`；
- 关键数字进入画面时使用 `count-up`，禁止闪跳。

## 误差与缺失

缺失值不得默认补零；误差表达优先区间而非单点；
样本不足时画面必须标注，不得用平滑曲线暗示精度。
